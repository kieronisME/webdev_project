
in order to contribute one must follow these simple steps

  

first git clone the repo

create a new branch

make a change

git add .

git commit -m""

git push -u origin ->branch name<-

  

go to the repo in github website, then in the code section you should be able to see a pull request on the top, click on that.
It will take you to a page that prompts you to compare and pull, click on that.

then wait for the checks to be done and click on merge
